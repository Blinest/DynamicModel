## 1. 几何层

### 1.1 基本量（定案）

| 项 | 值 | 说明 |
|---|---|---|
| 外/内半径 | 8.0 / 6.5 mm | Φ16、壁厚 1.5 |
| 周向组数 | 3 | 每圈 3 个 60° 周期 |
| 轴向节点间距 | `a = pa/2` | pa 由 α 决定 |
| 斜撑角 α | 段1 **34°** / 段2 **20°** | 段2 更"扁" |
| 筋宽 w | 两段均 **2.0 mm** | |
| 圆角 R | 段1 轴向 **5.0**（侧向尖）/ 段2 轴向 5.0 + 侧向 1.0 | 切线圆弧 |
| 孔族 | **正交 2 族**（错开 B, a） | 合起来铺满 |
| 间隔盘 | **20 个** ⇒ 20 段、每段 20 mm | |

### 1.2 关键公式

- 周向半节距 `B = 2πR_o/(2·N_circ) = 8.377 mm`（由 N_circ=3 锁死）
- 斜撑长 `L_strut = B/cosα`，轴向半对角 `a = L_strut·sinα`
- 孔径边 = 筋的**侧面** ⇒ 从筋中心线向孔内缩 `h = w/2`
- 圆角切点 `t = R/tan(φ/2)`、圆心距 `d = R/sin(φ/2)`（φ 为孔角夹角）

## 2. 刚度层（由几何推，不靠反标）

```python
EI = c · E · I_solid · f · sin²α·cos²α
EA = c_E · E · A_solid · f
GJ = c_G · G · J_solid · f
```

- `I_solid = π/4(R_o⁴−R_i⁴) = 1.815e-9`、`E·I_solid = 0.363 N·m²`
- `f` 为材料率（含圆角，网格统计）：段1 `0.44`、段2 `0.77`
- **标定常数只有一个** `c = 0.4367`，在 w=1.5 时由实测 `EI=0.01037` 标定，**之后固定不再重标**（否则加粗/减薄的效果会被对冲）

结果：

| 段 | EI | EA | GJ |
|---|---|---|---|
| 段1 | **0.01499** | 6013 N | 0.1102 |
| 段2 | **0.01266** | 10568 N | 0.1936 |

```bash
python cosserat_lattice.py     # 打印刚度表 + 力矩→弯角校核
```

## 3. 曲率场层（20 段）

### 3.1 表示

`κ = [κ_0 … κ_19]`（1/m），每段 20 mm。总弯角 `θ = Σ κ_i·0.02`。

### 3.2 两种生成方式

**(a) 由物理剖面生成**（`seg12_model.kappa_vec`）

```
w_i ∝ 1/(1+μ·C·s_i) × (s_i≤200mm ? 1 : 0.5)     # 摩擦根部集中 + 6丝/3丝
κ_i = θ·w_i^p / Σw_i / 段长                       # p 为集中指数
```

**(b) 由实测形状反求**（`kappa_fit.fit`）

最小化 `‖r(κ)‖² + λ‖D₂κ‖²`，`r` 含末端 `(x,z)` 与末端切向角 ⇒ 3 个观测对 20 个未知量，靠二阶差分正则化定解。

### 3.3 弯曲模式

| 模式 | κ 符号图样 |
|---|---|
| C 形 | 全同号 |
| S 形 | 后 10 段取反 |
| 反向 S | 前 10 段取反 |
| 波浪 | 每 5 段换号（4 个半波） |

```bash
python seg12_model.py     # 基线形状 + 目标位姿命中（粗网格搜索 + 局部细化）
python kappa_fit.py       # 曲率场拟合（残差 0.00 mm）
```

## 4. 驱动层

### 4.1 张力（`tdcr_control`）

```
τ_i = T0 + A·cos(α_i − φ),   α_i = 0/60/…/300°
A = κ1·EI/(3·r_disk)        # 保证力矩匹配
方位标定层：φ_cmd = (φ_target − 117°)/0.744
```

约束：`τ_min ≥ 0.5 N` ⇒ `A ≤ T0 − 0.5` ⇒ **可达弯角正比于预紧**（T0=5 N 约 133°）。

### 4.2 收丝量（**丝只能拉**）

```
δL_w = − r · θ_span_w · cos(θ_w − φ)      # θ_span: A 段丝只跨前 200 mm
ΔL_w = max(0, −δL_w)                       # 需伸长的丝 => 松弛，位移 0
```

⇒ **一个 C 形弯曲只有 3 根丝受拉、3 根松弛**。

| 模式（θ=90°, 方位 0） | M1 | M2/M6 | 其余 |
|---|---|---|---|
| C | 5.63 | 3.93 | 0 |
| S | 5.63 | 1.70 | 0 |
| 波浪 | 0.37 | 0.24 | 0 |

```bash
python tdcr_control.py     # 开环反解 24 组 + 闭环 3 步收敛
python tools/tension_scan.py
```

## 5. 渲染层

### 5.1 掩膜法（替代多边形叠加）

1. 展开坐标建网格（`DS` mm）
2. 每个孔（双向 2 族、带切线圆角）作多边形
3. `matplotlib.path` 判定每个格心是否在孔内（**包围盒预筛**，否则 2000+ 多边形 × 3 万点太慢）
4. 只渲染材料格：外表面 + 内表面 + 孔壁（材料与孔的公共边）

**关键**：掩膜随弯曲**逐行重建**（每行按 `ε(s)=κ(s)·R` 重算 `a,b`，杆长不变），压缩才会体现在孔形上。

### 5.2 受力着色

```
ε(θ,s) = −κ(s)·R·cos(θ−φ)        # ⚠ 符号：+x 是凹侧，θ=0 受压
F = E·(ε·sinα)·(w·t)
```

色标：深蓝（受拉）→ 浅蓝 → 近白 → 浅红 → 深红（受压）；`|F|/Fmax<2%` 置浅灰。
**全帧共用同一 `Fmax`**（取最大弯角帧的 95 分位），否则逐帧归一化会把变化吃掉。

### 5.3 出图/出视频

## 6. 三条踩过的坑（写进代码注释了）

1. **单位**：绘图脚本内部一律用米，只在标题/轴文字里换算成毫米。`PA`、`r`、`xlim` 各踩一次。
2. **坐标轴**：一律先锁 `xlim/ylim/zlim`（取最大变形帧的包围盒），否则相机跟着数据走 —— 一个把变化吃掉，一个把静止显示成运动。
3. **符号**：`build_frames` 绕 +y 正转 ⇒ 切线由 +z 偏 +x ⇒ **+x 是凹侧**，应变 `ε = −κ·R·cosθ`。写成正号会把受压侧算成受拉。
