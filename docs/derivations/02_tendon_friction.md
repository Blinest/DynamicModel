> `_jit_integrate.integrate_all` ｜ 出图：`tools/plot_friction.py`

## 1. 物理模型：为什么是指数衰减

取一段位于曲率 $\kappa(s)$ 骨架上的肌腱微元 $\mathrm{d}s$。肌腱张力 $T$ 在弯曲路径上产生指向曲率中心的法向压紧力

$$
\mathrm{d}N = T\,\mathrm{d}\theta = T\,\kappa\,\mathrm{d}s
$$

若肌腱相对导孔/骨架发生相对滑动，接触面摩擦（库仑，系数 $\mu$）沿切向作用、方向与相对滑动相反：

$$
\mathrm{d}F = \mu\,\mathrm{d}N = \mu\,T\,\kappa\,\mathrm{d}s
$$

沿弧长的张力平衡给出

$$
\mathrm{d}T = -\mu\,T\,\kappa\,\mathrm{d}s
\qquad\Longrightarrow\qquad
\boxed{\;T(s) = T_0\,\exp\!\bigl(-\mu\,\varphi(s)\bigr),\quad
\varphi(s)=\int_0^{s}\lvert\kappa\rvert\,\mathrm{d}s\;}
\tag{1}
$$

$\varphi$ 是**累积包角**（rad）。它就是经典 Capstan 公式 $T_{\text{out}}=T_{\text{in}}e^{-\mu\theta}$ 的分布形式。
注意 $\varphi$ **与丝的半径 $r_w$ 无关**（各丝与骨架同曲率），因此整条臂只需一个标量状态，实现代价极低。

## 2. 加载 / 卸载两支与滞回

(1) 式的符号取决于**相对滑动方向**：

| 状态 | 相对滑动 | 张力分布 | 实现 |
|------|----------|----------|------|
| 加载（拉紧） | 由远端流向基座 | $T(s)=T_0e^{-\mu\varphi}$（远端更小） | `friction_branch=+1`（默认） |
| 卸载（放松） | 由基座流向远端 | $T(s)=T_0e^{+\mu\varphi}$（远端更大） | `friction_branch=-1` |

同一 $\tau$/位形下两支的位姿之差就是**滞回环宽度**。严格的做法需要加载历史（或速率）来选支，
本实现把它暴露为显式参数，避免在准静态正解里偷偷引入路径依赖（见 §5 局限）。

## 3. 嵌入平衡方程的位置

原模型的六丝耦合项 $A,B,G,H,c,d$ 与锚点集中力都用**常数** $\tau_w$；摩擦让它们变成逐节点的 $\tau_w(s)$：

$$
\tau_w(s)=\tau_{w,0}\exp\!\bigl(-b\,\mu\,\varphi(s)\bigr),\qquad b\in\{+1,-1\}
$$

实现上只有三处变化（其余数学不变）：

1. 每个子步用**该节点**的 $\tau_w(s)$ 组装 $A,B,G,H,c,d$；
2. 子步末累积 $\varphi \mathrel{+}= \mathrm{d}s\,\lvert\kappa_{xy}(s_{\text{mid}})\rvert$（与 RK2 中点一致）；
3. 两个锚点（段界 $s=L_1$ 与末端 $s=L$）用**当地**张力 $\tau_w(\varphi_{\text{local}})$ 算集中力/矩。

$\mu=0$ 时这三处全部退化，代码路径与旧版**逐位一致**（§4）。

## 4. 数值验证

### 4.1 $\mu=0$ 回归（必须逐位一致）

改动前后（同一 $\tau$ 批、$n_p=n_d=60$、`TC_NO_JIT=1`、`TC_JAC_MODE=central`）：

```
μ=0 与改动前逐位一致: True | max|Δx| = 0.0      (x / res / tip 三个数组全部 array_equal)
```

### 4.2 摩擦打开后的影响（基准 $\tau=[40,20,40,20,40,10]$ N，$n_p=n_d=60$）

| $\mu$ | $\Delta p_{xy}$ [mm] | $\Delta p_z$ [mm] |
|-------|----------------------|-------------------|
| 0.05 | 0.01 → 1.06 | 0.00 → 0.15 |
| 0.15 | 0.03 → 3.09 | 0.00 → 0.44 |
| 0.30 | 0.05 → 5.92 | 0.00 → 0.86 |

（区间对应包角最小/最大的那两个样本；求解残差仍为 $\sim7.5\times10^{-9}$，说明加摩擦后打靶照常收敛。）

### 4.3 滞回环（$\mu=0.15$）

```
加载支 Δz = [0, 0.06, 0.17, 0.44] mm
卸载支 Δz = [0, -0.06, -0.17, -0.48] mm
环宽 Δz  = [0, 0.12, 0.35, 0.92] mm      ← 与 (2) 式的对称性一致 (≈2×加载偏移)
```

**量级结论**：$\mu=0.15$ 时摩擦造成的末端漂移在毫米级，与"表点间距 NN 中位 4.6 mm"的精度下限**同量级**
⇒ 若目标精度是亚毫米，摩擦项**必须**建；若只要求毫米级，可以先用 $\mu\approx0.1$ 做保守修正。

## 5. 局限与后续

1. **速率无关**：没有 Stribeck/粘性项，也没有静摩擦锁死（$\mu\to$ 有限时低张力下仍会滑动）。
2. **支的选择靠参数**：真实系统里支由历史决定，要做到自动滞回需要在 `solve_pose` 外层记录 $\mathrm{d}\tau$ 符号。
3. **只考虑弯曲包角**：导孔处的局部偏折（丝在孔内的进出角）没算，若导孔偏心大，$\varphi$ 会低估。
4. **$\mu$ 待标定**：`calibration.py` 已有标定框架，可把 $\mu$ 作为待辨识参数，用不同 $\tau$ 幅值的往返轨迹拟出滞回环宽度。
