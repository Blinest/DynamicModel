## 2. 单胞 → 等效弯曲刚度

### 2.1 应变能

管弯曲曲率 `κ` 时，截面在周向位置 `θ` 处的轴向应变

    ε(θ) = κ · R · cos(θ − φ_b)          （φ_b 为弯曲平面方位）

斜撑两端的轴向位移差把这一应变转换为斜撑的伸缩：

    ΔL_strut ≈ κ · R · cos(θ−φ_b) · ℓ_proj

其中 `ℓ_proj` 是斜撑在管轴方向上的**有效臂长**，取值 `pitch_c/2`。

单胞应变能 `U = ½ · (E·A_s/L_s) · ΔL²`，对整圈 `N_c` 个斜撑求和（`Σcos² = N_c/2`）：

    EI_bend-insensitive = N_c · E·A_s / L_s · R² · sin²α · (pitch_c/2) · n_cell

`n_cell = N_long/L_seg` 为单位长度的胞数。

### 2.2 两条极限

| 路径 | 假设 | EI (N·m²) | 与标定之比 |
|---|---|---|---|
| **(A) 轴向主导** | 斜撑只受拉压 | 0.864 | **83×** ❌ |
| **(B) 弯曲主导** | 斜撑当两端固支短梁 `3EI_s/L_s³` | **0.0070** | 0.67 ❌ |
| **(C) 晶胞公式** | `cell_stiffness`（A=2.25 mm²） | **0.0153** | 1.47 |
| **(C′) 晶胞公式** | `cell_stiffness`（A=1.5 mm²，代码默认） | **0.0102** | 0.98 ✓ |
| ★ 实测标定 | 30° 四方位 + 60/90° 复核 | **0.01037** | — |

### 2.3 结论

1. **(A) 被排除**：高 83 倍，说明"斜撑只拉压"的假设完全错——菱形胞的柔性来自**机构开合**，不是杆件伸缩。
2. **标定值 0.01037 落在 [0.0070, 0.0153] 内** ⇒ 几何推导**包住了**实测值，一致性检查通过。
3. **斜撑截面 `A_s` 是唯一能调和几何与实测的自由量**：

   | `A_s` | 等效截面 | EI0 |
   |---|---|---|
   | 1.5 mm² | 1.5×1.0 | 0.0102（吻合 1.9%） |
   | 2.25 mm² | 1.5×1.5（真实） | 0.0153（高 47%） |

   ⇒ `build_arm(A=1.5e-6)` 里的 `1.5 mm²` 实质是一个**等效斜撑截面**，不是真实 1.5×1.5。

4. **相对无孔管的折减**：`E·I_solid = 0.363` → `0.01037`，**折减 35 倍**，只剩 **2.86%**。这是"周向几乎被掏空"的直接后果。

## 3. 等效轴向刚度

斜撑在轴向（管轴）方向的串联刚度：

    k_rod = N_c · E·A_s / L_s · cos²α · (与胞数成正比)

- 晶胞公式（A=2.25 mm²）：`k_rod = 2384 N`
- 代码标定：`k_rod = 7000 N`
- 差额来自 **6 根 NiTi 丝**：丝是轴向结构件，并联进来把轴向刚度抬到 7000 N。晶胞公式只算聚合物骨架，两者不矛盾。

**注意**：`k_rod` 直接进入 `ΔL = r·θ + ΣT/k_rod`。若实测"没有轴向压缩"（ΣT=30 N 时 δ<0.1 mm），则 `k_rod > 300 N/mm = 3×10⁵ N`，比 7000 高两个量级——这条与标定值冲突，**尚未闭合**。

## 4. Cosserat 平衡方程

状态 `y(s) = [p; R; n; m]`（位置、姿态、内力、内力矩），以 `f = M⁻¹r` 形式写成显式一阶系统：

    p' = R·v
    R' = R·[κ]×
    n' = −f_v − p̂'·τ_w          （f_v: 分布重力 + 腱的横向分量）
    m' = −p'×n − l_v

本构：

    v = 1 + K_se⁻¹·n,     κ = K_bt⁻¹·m

其中 `K_se = diag(EA, GA, GA)`、`K_bt = diag(EI, EI, GJ)`。

**腱耦合**：第 `j` 根腱在截面上的力臂

    r_j = R · o_j,     o_j = r_disk·(cos α_j, sin α_j, 0)

贡献到内力/力矩：

    n_tau = Σ_j τ_j · p̂'_j,     m_tau = Σ_j r_j × (τ_j p̂'_j)

摩擦（Capstan）：`T_j(s) = T_j0 · exp(−μ·φ_j(s))`，`φ_j` 为累积包角。

## 5. 边界条件与求解

**悬臂**：`s=0` 固支 `p=0, R=I`；`s=L` 自由端受 `F_tip`、无力矩。

未知量为根部状态 `x₀ = [v₀(3); u₀(3)]`（轴向应变 + 曲率），打靶求 `res(x₀) = 0`：

    res = [ n(L) − F_tip ;  m(L) ]

用 Newton + 解析雅可比（`tools/varjac/`，对拍 1e-12 量级）迭代。

**可解性**：`res: R⁶→R⁶`。直杆构型下 `∂res/∂x₀` 在"弱方向"接近奇异（σ_min ≈ 0.0082）⇒ 大偏向时需 pre-condition 或降步长。

## 7. 尚未闭合的两条

1. **`k_rod`**：晶胞 2384 N、标定 7000 N、"无轴向压缩"要求 >3×10⁵ N —— 三者不一致。
2. **`A_s` 的取值**：1.5 mm² 使 EI 吻合、2.25 mm²（真实）高出 47%；需一次单胞级试验（拉伸/弯曲）实测。
