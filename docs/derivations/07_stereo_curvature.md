# 双目视觉标定臂体曲率：方案与验证

> 2026-10-10 ｜ 代码：`tools/stereo/sterelib.py`、`tools/stereo/selftest_math.py`
> 思源笔记同名文档：`/空间臂形的标定策略`（含完整公式与实测表）
> 定位：这是「实机精度闭环」这一条独立线，不在 `README.md` 的 ①–⑥ 推导清单里

---

## 1. 结论先行

两台相机可以给出空间 3D 点。**平面棋盘只是标定工具，空间点是三角化算出来的**——
被测物不必是平面，也不必已知 3D 标定物。真正需要已知空间坐标的只有
「相机系 → 臂基座系」一步，且这些点**必须非共面**（§5）。

## 2. 数据流

```
τ/ΔL 指令 → 臂形 → 双目成像 → ArUco 检测(ID 免匹配) → undistortPoints
   → 三角化 → 基座系变换 → 3D 点列 → κ(s) → 与模型 kS/kK 对拍 → 增益 g → EI 修正
```

左右对应由 **ArUco ID** 直接解决；无 ID 只能靠极线 + 沿臂顺序约束，易错配。

## 3. 标定三步

1. 双目标定（~20 min）：棋盘 15–20 位姿 → `calibrateCamera` ×2 → `stereoCalibrate` → R,t；验收重投影 RMS < 0.3 px
2. 基座系对齐（~20 min）：基座上刚接 **L 形双面板**（≈90°，各 3 个定位孔），孔位坐标由 CAD/卡尺给出 → Kabsch；验收残差 < 0.3 mm
3. marker 布置（~30 min）：20 个 ArUco，h ≈ 22 mm；marker₀ 贴基座夹持面（δ≈0）

## 4. 曲率反算的三个坑（都用 selftest 量化过）

### 4.1 三点外接圆精确，但噪声 ∝ 1/h²
κ = 4S/(l₁l₂l₃)，S 为三角形面积。对圆弧**精确无离散偏差**，但点密反而更差。

### 4.2 窗拟合 + 解析偏差修正（推荐）
局部平面内二次拟合 v(u)，κ = |v''|/(1+v'²)^{3/2}；二次拟合圆弧**系统性高估**
5U²/(28R²)（U=窗半宽），迭代 2 次 κ ← κ/(1+5U²κ²/28) 即消掉。

### 4.3 段界 L1 必须按「窗跨度」剔除
L1 处 κ 有物理跃变，滑窗跨过即污染。**剔除半宽要按 k·h 而非固定带宽**：
不剔时偏差 ~4.4%，且**多帧平均消不掉**（是偏差不是噪声）。

## 5. 基座对齐：共面点差 21 倍而 RMS 看不出

点位噪声 0.2 mm、各 200 次实测：

| 已知点集 | 转角误差中位 | 对齐 RMS |
| --- | --- | --- |
| 非共面（臂点 + 2 个离面点） | **0.093°** | 0.297 mm |
| 共面（只用臂上点，臂是平面曲线 ⇒ 天然共面） | **1.945°** | 0.276 mm |

只看 RMS 会误判「已对齐」。**基座必须另布 2 个离面已知点。**

## 6. 精度：理论预算 + 实测

理论（B=0.5 m，f=1200 px，z=0.5 m，δd=0.2 px）：δz = z²δd/(fB) ≈ **0.083 mm**，δx = z·δd/f ≈ **0.083 mm**

实测（视距 0.55 m，σ=0.2 px）：

| 项 | 结果 |
| --- | --- |
| 三角化位置 RMSE | **0.157 mm** |
| 曲率 w=1 严三点 | 单帧 13.3% → 30 帧 2.1% |
| 曲率 w=3 局部二次 | **单帧 1.20% → 30 帧 0.68%** |
| κ 矢量 ⟂ 切向 | max\|cos∠\| = 0.043 |

marker 密度权衡（反直觉：贴密更差）：

| 点数 | h(mm) | w=2 单帧/30帧(可用点) | w=3 单帧/30帧(可用点) |
| --- | --- | --- | --- |
| 12 | 38.2 | 1.09% / 0.69% (4) | — / — (0) |
| 20 | 22.1 | 2.26% / 0.56% (12) | **1.17% / 0.69% (8)** ← 推荐 |
| 32 | 13.5 | 7.08% / 1.66% (24) | 2.97% / 1.01% (20) |

⇒ **20 marker + window=3 + 单点 30 帧平均 → κ 误差 ~0.7%**

## 7. 采集：准静态不需要硬同步

臂是准静态 ⇒「走一步—停稳—拍 30 帧」。判稳用连续两帧 marker 位移 < 0.02 px；
`grab()` 后 `retrieve()` 成对取以减小时间偏斜；按 marker 取 30 帧**中位数**抗离群。

## 8. 修正回路

公共 s 网格上（剔除段界）最小二乘增益 g = Σκ_r·κ_m / Σκ_m·κ_m，分段给 g_A、g_B。
由 κ ≈ M/EI：**EI_real = EI_model / g**，直接乘到 `SDMParams.EI0`（段 A）/`EI`（段 B）。

自检已验：人为把模型 κ 缩小 1.1 倍 → 实测 g = 1.0894（真值 1.1），gA = 1.0984，gB = 1.0859。

**弧长原点偏移 δ**：实测 s 从 marker₀ 起算、模型从基座起算，差一个未知常数。
估计弱可辨识（同段内 κ 模为常数，只有方向可辨）⇒ 工程上把 marker₀ 贴基座面。
