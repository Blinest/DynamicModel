# model/ — 精简版位姿表（入库用）

| 文件 | 点数 | 大小 | 弯角 |
|---|---|---|---|
| `vc_table_20.npz` | 900 | 2.34 MB | 0.6–84.0° |
| `vc_table_40.npz` | 776 | 2.04 MB | 1.4–121.7° |

## 与完整版的差别

只把 **κ 曲线节点从 601 抽到 61**（每 10 个取 1 个），其余字段
（`tau` / `dL_mm` / `p_tip` / `R_tip` / `res` / `x`）**完全一致**。

- 用途：查表逆解、位姿分布、点间距统计 —— 完全够用
- 差别：画曲率剖面时节点从 0.74 mm 变 7.4 mm，精度略有下降
- 体积：38.3 MB → **4.4 MB（8.7 倍）**

## 用法

```bash
cp model/vc_table_*.npz .          # 放回仓库根目录
python main.py info                # 验收 version_ok
```

完整版（601 节点）不入库，需要时重建：

```bash
python main.py build 20 40 --force
```
